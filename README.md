
# Kivora

**Simple, powerful online tools for everyday tasks.**

Kivora is a collection of lightweight, easy-to-use web utilities designed to help students, developers, and professionals get everyday tasks done quickly.

Our goal is to bring useful tools together in one clean, accessible place, with a consistent experience across every tool.

## ✨ Features

- **JSON Formatter** – Format, minify, and validate JSON with helpful error messages.
- **Modern UI** – Clean, responsive and user-friendly interface.
- **Fast & Lightweight** – Designed for a smooth user experience.
- **More Tools Coming Soon** – Continuously expanding collection of useful utilities.

## 🛠️ Tech Stack

- **Next.js** – React framework
- **React** – UI development
- **TypeScript** – Type safety
- **Tailwind CSS** – Styling
- **Lucide React** – Icons

## 🚀 Getting Started

Follow these instructions to run Kivora locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rakshit-jain2/kivora
   ```

2. Navigate to the project directory:

   ```bash
   cd Kivora
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```
